# Dissect

1. Inspect the source and identify meaningful objects, overlap order and source dimensions where available. Keep a compact plan, normally 3–6 useful objects rather than dozens of fragments. If the user selected objects, honor that scope.
2. Preserve the source unchanged. Distinguish exact extraction of visible pixels from generative isolation/reconstruction. Native generative editing can alter details and hidden areas must be invented. If exact pixels are required and no suitable segmentation/masking tool is available, explain the blocker rather than silently regenerate.
3. Prepare one named transparent object per output, reference the same original for each, retain complete boundaries and consistent scale. Preserve exact source typography separately where possible; never invent authentic letters or markings. Apply selected HD/noise/reimagine directions to the relevant object only.
4. Display each result and checkpoint its actual reference before beginning the next. Inspect available alpha/boundary evidence, placement and clipping. Do not assert pixel-level alpha validation unless performed. Keep reconstruction uncertainty visible.
5. Return completed outputs even if another object fails. If LUM saving was requested, bridge each completed object independently. Do not withhold the whole result until all uploads succeed.
6. A finished dissect consists of usable named outputs, not just a plan. Report incomplete objects honestly. Only claim an editable LUM project after saved layers have been read back.
